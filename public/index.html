About IrisAI Project

IrisAI is an end-to-end Machine Learning laboratory designed for high-precision botanical classification and exploratory data analysis.

Originally collected by American botanist Edgar Anderson (1935) in the Gaspé Peninsula and popularized by statistician Ronald A. Fisher (1936), the Iris dataset represents the gold standard benchmark for linear discriminant analysis.

• Pipeline: StandardScaler + K-Nearest Neighbors (k=3)
• UI Design: Stitch Project 14704649354205307970
• Backend: Native Python REST Server (Zero Dep)
